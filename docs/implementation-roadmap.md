# Implementation Roadmap

## Phase 1: Static Prototype

- Build campaign setup fields.
- Build subject and preheader editor.
- Build structured email body editor.
- Add CTA controls.
- Add live branded preview.
- Add rule-based correction hints.
- Add starter HTML and MJML templates.

## Phase 2: Production Builder

- Move prototype to React or Next.js.
- Add block-based drag-and-drop with dnd-kit.
- Add rich text editing with TipTap or Lexical.
- Persist templates and campaigns in PostgreSQL.
- Add user roles and approval workflow.
- Add image asset management.

## Phase 3: AI And Automation

- Add AI grammar and tone correction.
- Add brand consistency scoring.
- Add subject line generation.
- Add CTA optimization.
- Add banner recommendation prompts.
- Add campaign brief generation.

## Phase 4: Integrations

- Add Mailchimp, HubSpot, Zoho Campaigns, SendGrid, and Brevo exports.
- Add CRM personalization field mapping.
- Add UTM builder.
- Add analytics dashboard.
- Add A/B testing management.

## Phase 5: Enterprise Readiness

- Add audit history.
- Add version control for templates.
- Add brand lock controls.
- Add multi-brand support.
- Add advanced segmentation.
- Add email client rendering tests.
